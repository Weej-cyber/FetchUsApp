What Is FetchUs

The App in Plain Terms

FetchUs is a mobile-friendly web app built specifically for your dog walking business. It replaces manual scheduling, texts, and spreadsheets with a single system that your clients, walkers, and you all use from your phones.

There is nothing to download from an app store. Everyone accesses it through a link in their browser, and it works like an app on any phone.

Who Uses It

The Three Roles

Admin (You)

  • Add and manage clients
  • Add dogs to client profiles
  • View and assign walk requests
  • See all scheduled and past walks
  • Send broadcast messages to clients
  • Add walkers to the system

Walker

  • See their assigned walks for the day
  • Start and complete walks
  • Add a note and photo when finishing
  • View their walk history

Client

  • View their dogs' profiles
  • Request a walk
  • See upcoming and past walks
  • Receive notifications
  • Update their profile and home access info
How People Log In

Magic Link Login

There are no passwords. When a new user is added, they receive a single-tap login link by email. They tap the link and they're in. Returning users request a new link the same way. This is simpler and more secure than passwords.

Adding a new user: Log into the Supabase dashboard, go to Authentication, and invite the user by email. They receive a link automatically. Their role (admin, walker, or client) is set at that point.
What's Built

Current Status

  • Login and role routing — All three roles log in and land on the correct screen.
  • Admin portal — Client management, dog management, walk requests, booking assignment, history.
  • Walker dashboard — Assigned walks, start/complete walk, completion notes and photos.
  • Client portal — Dog profiles, walk booking, status tracking, notifications, profile editing.
  • In-app notifications — Notifications appear inside the app when a walk is assigned or completed.
  • SMS text notifications — Built but not yet connected. Clients will receive a text when their walk is confirmed and when it's completed. This is the next item on the roadmap.
What's Coming

Next Steps

SMS Notifications via Twilio

When a walker is assigned to a booking, the client gets a text. When the walk is completed, the client gets a text with the walker's note. The infrastructure for this is built -- it needs a Twilio account connected to finish it.

UAT Sign-Off

A full round of user acceptance testing is in progress across all three roles to confirm everything works before live use.
